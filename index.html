Trading Agent

Home page and privacy policy

Trading Agent is a personal tool used by one person, its owner (kadelbarbera@gmail.com). It is not offered to anyone else, and no one else can sign in to it.

Privacy Policy

Last updated: October 5, 2026

Google data the app uses

The app uses one Google permission: the Google Drive scope https://www.googleapis.com/auth/drive. It uses it only to read and write the owner's own trading records, which are JSON and CSV files kept in Drive folders the owner set up for this tool. It does not use this access for anything else.

The app also sends the owner notification emails through Gmail using an app password. It does not read the owner's mail.

Where data is kept

The data stays in the owner's own Google Drive and in the owner's own Google Cloud project, where the app runs.

Sharing

The data is not shared, not sold, not used for advertising, and not read by other people.

Google API Services User Data Policy

Trading Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the app's access at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: kadelbarbera@gmail.com
